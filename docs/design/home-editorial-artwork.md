# Home editorial artwork

Created with the built-in image generation tool for the mobile home carousel. Original generated images were copied without visual modification. The Sanctuary brand logo remains the existing asset.

Runtime copies:

- iOS: `apps/ios/Sanctuary/Assets.xcassets/HomeEditorial{Welcome,Scripture,Rosary}.imageset/`
- Android: `apps/android/app/src/main/assets/home_editorial/{welcome,scripture,rosary}.png`

The hero uses the portrait artwork with a native gradient for text readability. List thumbnails and landscape shelves crop the same images; artwork can be replaced independently of navigation.
