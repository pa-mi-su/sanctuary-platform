# News CMS audit — October 13, 2026

Scope: local news/admin implementation on codex/sanctuary-news-fresh-start. No deployment, MAIN write, or cloud-account changes were performed during this audit.

## Findings fixed

1. The Angular API service accepted a trash flag but omitted it from the HTTP request. The Trash view therefore retrieved active articles. The service now sends trash=true/false explicitly. New HttpTestingController tests verify the actual URL, cookies, mutation header, and optimistic version parameters.
2. An authorization failure during save cleared the editor's in-memory article. Unsaved text now survives session expiry and is restored to the editor after reauthentication. Explicit sign-out still clears private editor state. This is memory preservation, not browser-persistent autosave.
3. Dirty checking omitted the editor-only scheduled publication field. Scheduled-time changes are now included in the snapshot comparison.
4. JWT validation failure after a slow MFA enrollment could escape as a server error. It now returns an actionable 401 requiring a new sign-in.
5. Default article-validation handling could echo rejected private draft text into validation logs. The controller now handles validation errors and returns field names only. HTTP tests verify oversized private text is absent from the response.
6. npm reported 38 dependency advisories initially. Compatible Angular 21.2 runtime/build patch updates and transitive fixes reduced the final npm audit result to zero. No major Angular upgrade or forced audit fixes were used.
7. News/admin screens were eagerly bundled with the companion app. Angular deferred imports now load those screens separately. The final initial bundle is 572.45 kB (estimated transfer 125.18 kB), down from 642.44 kB before splitting.

## Design assessment

Useful foundations are in place: Angular API adapters and standalone components, deferred screen loading, dependency injection, validated immutable Java request/response records, parameterized JDBC operations, database constraints, transactional lifecycle/placement changes, optimistic versions, audit records, and separate server authorization/MFA proof checks.

This is a small first-version CMS, not a claim of architectural perfection. The MFA controller owns orchestration and process-local challenge state; a service/challenge-store extraction is appropriate before multi-replica operation. The repository currently combines SQL with lifecycle invariants and does per-article correction queries. Split these responsibilities and batch/paginate reads as the publication grows. Neither refactor is required to operate the current single-editor local setup.

## Remaining notices and production gates

- Build warnings remain: initial assets exceed the existing 500 kB warning budget (below the 1 MB error budget), and the QR encoder is CommonJS. A temporary build of unmodified MAIN source with the patched tooling was already 537.78 kB, confirming baseline budget debt. Do not increase warning thresholds simply to conceal it. Further optimization can focus on the existing companion-app screens.
- Use durable database storage and ongoing backups for real content. The current Docker container is disposable; the audited dump is a point-in-time safeguard, not an ongoing backup strategy.
- Confirm the deployed API IAM role can resolve the canonical Cognito username when challenge parameters omit it: cognito-idp:AdminGetUser, scoped to the appropriate environment's user-pool ARN. Local testing used the developer's AWS identity, so it does not prove ECS role permission. Do not grant wildcard Cognito access.
- Production administrator provisioning/enrollment, recovery, role transfer away from the everyday account, and actual deployed DEV acceptance testing remain release tasks. Production MFA was not changed by this audit.
- Pending MFA challenges are process-local; use shared protected short-lived storage or a tested routing strategy before multiple API replicas. Completed MFA proofs are database-backed.
- The current list is capped at 100 full articles and lacks pagination; introduce pagination/batched correction fetching before growth exceeds that limit.
- Article query links work, but permanent canonical article routes, unique metadata, sitemap/social previews for news, and admin/sample noindex rules remain launch work.
- A full penetration test, JVM dependency advisory scan, production load test, and editorial/legal review were not part of this local functional audit.

## Security follow-up: not approved for public launch

The functional audit is not a security certification. Additional source inspection identified the following unresolved security gates; no production exploit testing was performed.

- AuthAbuseProtectionFilter trusts the first X-Forwarded-For value, falling back to X-Real-IP. A caller able to control these headers can change the rate-limit key. Verify the exact proxy topology and sanitization, then use a trusted client-IP source and test spoofed headers. Its counters are process-local and retain expired keys; bound storage and enforce abuse limits across replicas or at the edge.
- JWT audience validation becomes issuer-only if the configured audience is empty. Require the intended client configuration for admin authentication, explicitly validate token type, and test wrong-client, wrong-issuer, expired, and malformed real signed tokens.
- Removing a Cognito group membership does not immediately invalidate an already-issued JWT and MFA proof. Implement and test per-administrator session revocation and document emergency access removal; the current proof schema lacks a user identifier for targeted revocation.
- Verify deployed HTTPS/cookie/CORS settings and hostile-origin requests. The mutation-header control depends on trusted CORS configuration; local tests do not establish production settings.
- Complete Java dependency vulnerability scanning and independent security review, then exercise the actual DEV deployment with real Cognito credentials under an agreed test scope. The available code-review tool reads PR CI diagnostics and does not supply an independent local security assessment.
