# Desktop menu and direct newsroom links

The shared header had six navigation tabs in a five-column desktop grid, pushing Sign in onto a second row. It now uses six equal desktop columns, matching 52px control heights, consistent borders/corners/spacing, concise sign-in/language labels and visible keyboard focus. Narrow layouts remain deliberate separate rows. Desktop/web version is 1.0.17; native app source and versions are unchanged.

Direct `/admin/news` returned S3 AccessDenied XML because the private S3 REST origin serves exact object keys; its default root object applies to `/`, and there was no object for this app route. The web deploy workflows now publish the already-built/hardened public app shell at six exact keys: `news`, `news/`, `admin`, `admin/`, `admin/news`, `admin/news/`. Each has HTML content type and no-cache. This also fixes refresh/direct links to the public news page. No CloudFront blanket 403-to-200 fallback, permission expansion, auth bypass or private-data prerendering is introduced. Cognito/group/MFA checks remain enforced by the API.

The publisher refuses cross-environment/unknown buckets and missing build output. Fake-AWS regression tests verify both environment targets, exact trailing-slash keys, HTML metadata, retained CSP and no writes for invalid targets. Local web tests: 31 passed; production build passed with existing bundle/CommonJS warnings. Desktop layout inspected in the browser at screenshot width, with all controls aligned and equal height.
